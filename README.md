Site one-page da **JNC Soluções**: consultoria e soluções técnicas para sistemas de GLP (Gás Liquefeito de Petróleo) em São Paulo, com atendimento 24 horas.

## Estrutura

```
index.html   # página única (hero, sobre, soluções, como funciona, contato com mapa, FAQ)
styles.css   # estilos (azul-marinho, dourado e cinza do logo, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # logo, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.
