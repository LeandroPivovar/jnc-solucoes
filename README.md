# JNC Soluções - site institucional

Site one-page da **JNC Soluções**: consultoria e serviços de engenharia em São Paulo, com atendimento 24 horas.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, como funciona, contato com mapa, FAQ)
styles.css   # estilos (azul-marinho, dourado e cinza do logo, modo claro/escuro automático)
script.js    # menu mobile, header ao rolar, animações de entrada, FAQ
assets/      # logo, favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Antes de publicar

- **Serviços:** o perfil do WhatsApp diz só "Consultoria e serviços de engenharia". Os cards (consultoria, acompanhamento de obras, projetos, laudos e vistorias, planejamento e orçamento) são uma proposta. Confira com o cliente ou com o catálogo do WhatsApp e ajuste.
- **Endereço:** o perfil mostra apenas **São Paulo, SP**. O mapa mostra a cidade. Se houver endereço, troque a busca do `iframe` no `index.html`.
- **Logo:** `assets/logo-jnc.png` foi recortado do print do perfil do WhatsApp (178px). Troque pelo arquivo original em alta resolução quando tiver.
- **Fotos:** são de banco de imagens. Fotos reais de projetos e obras da JNC deixam o site mais forte.
- **Depoimentos:** não há seção de depoimentos para não publicar avaliações inventadas. Dá para adicionar com avaliações reais.
